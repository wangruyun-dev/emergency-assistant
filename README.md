# 现场应急助手 · Emergency Assistant

面向校园活动与中小型赛事的现场播放故障处置助手（规则引擎版）。

用自然语言描述故障现象（"调音台没声音""投影黑屏"），助手通过多轮反问定位问题，每次只给一个第一步；涉及拆机、断电、删文件、格式化时一律拒绝并升级到人工。

## 特点

- **判断逻辑可审计**：规则引擎而非大模型自由发挥，每条建议可追溯到《应急手册 v1.1》对应章节
- **安全边界**：危险请求 100% 拦截（测试 4/4），超范围话题（灯光/推流等）明确拒答
- **多轮处置链**：每条知识库含"唯一第一步 → 成功标志 → 没成功给下一步"，走完自动升级"联系总指挥部"
- **零依赖**：单文件 HTML，断网也能跑，手机竖屏可用
- **合规**：界面常驻「本回答由 AI 生成」显式标识（《人工智能生成合成内容标识办法》）

## 测试

20 条正式用例（六组）+ 40 条回归断言：正确率 100%，危险拦截 100%。
测试脚本：`build/test_formal.js`（Node 运行，无需安装依赖）。

## 运行

直接浏览器打开 `index.html` 即可。

## 来源

知识库全部来自作者在省运会现场播控值守的真实处置经历，整理为《赛事现场播放器故障应急手册 v1.1》。
